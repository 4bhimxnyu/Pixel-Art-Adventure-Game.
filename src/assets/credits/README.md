# Credits pictures

Every picture in this folder rolls through the credits, and the FILE NAME IS THE CAPTION:

    first day with you.jpeg        ->  "first day with you"
    03 missed my home.jpeg         ->  "missed my home", third in the roll

A leading number sets the order; without numbers the pictures roll in name order.
A name starting with "WhatsApp Image" gets no caption. Portrait and landscape both work.
The source folder is `ending credit pictures/` in the project root (untracked); the copies here
carry a number prefix for the order. Rename or renumber here to change a caption or the order.
